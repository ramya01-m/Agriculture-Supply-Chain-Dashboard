# Agriculture Supply Chain Performance Dashboard

## 📌 Project Overview

The **Agriculture Supply Chain Performance Dashboard** is an end-to-end data analytics project developed to analyze agricultural supply chain performance, spoilage risk, resource utilization, and profitability.

The project uses **Excel, SQL Server, SSMS, Python, and Power BI** to clean, analyze, and visualize the data.

---

## 🎯 Project Objectives

* Analyze agricultural supply chain performance.
* Identify factors contributing to spoilage risk.
* Analyze crop, region, and supply chain performance.
* Monitor profitability and resource utilization.
* Perform risk scoring and scenario analysis.

---

## 🛠️ Tools & Technologies

* **Excel** – Data cleaning and preparation
* **SQL Server** – Database storage and analysis
* **SSMS** – SQL query execution
* **Python / Jupyter Notebook** – Data analysis and visualization
* **Power BI** – Interactive dashboard and analytics
* **DAX & What-If Analysis** – Risk scoring and scenario analysis

## 📊 Power BI Dashboard

The Power BI dashboard contains **4 analytical pages**:

### 1. Overview

Provides an overall view of agricultural supply chain performance using key KPIs and visualizations.

### 2. Supply Chain and Risk

Analyzes supply chain factors and identifies areas associated with higher operational and spoilage risk.

### 3. Risk Scoring

Provides batch-level risk scoring using relevant supply chain and environmental factors.

### 4. What-If Analytics

Uses Power BI What-If Analysis to explore how changes in selected parameters can affect business outcomes.
